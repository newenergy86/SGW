# SGW — Satellite Modbus Gateway

Проект специализированного шлюза для замены Moxa NPort в системе передачи последовательных данных через IP-канал с высокой задержкой.

## Текущий этап

**SGW V0: протокол-независимый Serial ↔ IP bridge.** На первом этапе SGW пересылает произвольный поток байтов и не анализирует Modbus или смысл передаваемых данных.

## Лабораторный стенд

- В наличии: 1 плата ESP32-S3, временно выделенная из другого проекта.
- Заказано для целевого прототипа: 2 × ESP32-S3 и 2 × W5500.
- Временная сеть для первого эксперимента: Wi-Fi на ESP32-S3.
- Целевой транспортный интерфейс прототипа: Ethernet через W5500.
- Последовательная сторона: UART ESP32-S3 через подходящий RS-232 трансивер. Логические UART 3,3 В нельзя подключать непосредственно к электрическому интерфейсу RS-232.
- Следующая проверка совместимости: подключение к Moxa NPort после выяснения модели, режима порта и параметров serial/network.

## Ближайшая цель

Использовать имеющуюся ESP32-S3 как временный Wi-Fi/TCP узел и проверить сетевую часть взаимодействия с Moxa. Не считать этот стенд готовым Serial-to-IP bridge, пока не подключён RS-232-трансивер и не проверен двунаправленный поток байтов.
