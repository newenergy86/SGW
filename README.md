# SGW — Satellite Modbus Gateway

Проект специализированного шлюза для передачи Modbus RTU через высоколатентный спутниковый IP-канал.

## Статус

Лабораторный прототип: 2 × ESP32-S3 + 2 × W5500.

Цель первого этапа — построить два двухпортовых узла, проверить прозрачную передачу Modbus RTU, совместимость с Moxa NPort, а затем испытать оптимизированный транспорт при RTT около 2200 мс.

## Принцип разработки

Сначала совместимость, затем оптимизация. Все существенные решения и результаты испытаний должны фиксироваться в репозитории.
